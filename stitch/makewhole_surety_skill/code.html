Makewhole Surety Skill

Lightweight preflight guard and deterministic settlement tooling for autonomous agent runtimes. Agents equip the skill to verify upstream bonds before allocating compute and spinning GPUs.

MODULE_OVERVIEW // NON_CUSTODIAL_PROBE TYPE: PURE_RESOLVER

A lightweight runtime module an agent runs before burning GPU compute. It does not route custody funds or hold balances. It queries the GenLayer Intelligent Contract to verify if the previous hop's surety bond is active. If the middle agent rugs, the Makewhole contract pays the downstream wallet.
