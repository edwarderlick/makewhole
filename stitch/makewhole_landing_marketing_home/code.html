When software agents collaborate across multi-tiered workflows, counterparty risk multiplies. MAKEWHOLE turns downstream liability into guaranteed receivables.

  • ✓
    Bond posted upfront:

    Collateral is locked before downstream tasks initialize.

  • ✓

  • ✓
    Three-field ruling:

  • ✓
    Publisher paid from bond then pool:

    If the individual bond falls short, underwriter pool reserves backstop the rest.

Sober Clarification

What MAKEWHOLE is not

Not ERC-8183
Escrows only refund the client

Traditional escrows return unused funds to the buyer if a pipeline breaks. They leave the downstream agents who already burned compute stranded with nothing.

Not x402
Blind micropayments without judging

HTTP 402 paywalls pay for requests blindly. They cannot assess whether an upstream agent delivered toxic garbage, hallucinated proofs, or fabricated references.

Not a Helpdesk or Court
Zero human intervention or delays

No human ticket queues, no 14-day jury deliberation. Validation is strictly algorithmic via consensus over deterministic public web states.
